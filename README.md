# BusSpot

BusSpot is a bachelor's thesis project for managing and monitoring public transport.

The system provides tools for managing stops, lines, vehicles, drivers, and scheduled runs, as well as tracking vehicle locations and comparing planned routes with real movement data.

## Tech Stack

- **Backend:** Rust, Axum, Tokio, SQLx
- **Database:** PostgreSQL, PostGIS
- **Frontend:** React, TypeScript
- **Maps:** Leaflet, OpenStreetMap

## Planned Features

- Stop and line management
- Vehicle and driver management
- Course scheduling and conflict detection
- Live vehicle GPS tracking
- Route visualization on a map
- Historical trip analysis
- Planned vs actual travel comparison
- Public transport route search
